# Космический Шутер (Space Shooter Game)

## Описание
Красочная 2D игра в жанре космического шутера с динамичной графикой и системой сохранения рекордов.

## Особенности
- 🎮 Динамичный геймплей
- ✨ Анимированный фон со звездами
- 🎨 Красивая графика с цветными кораблями
- 💾 Сохранение рекорда в реестре Windows или файле конфигурации
- 🏆 Система личных рекордов

## Требования
- Python 3.x
- Pygame

## Установка
```bash
pip install pygame
```

## Запуск игры
```bash
python game.py
```

## Управление
- **Стрелка влево/вправо** - перемещение корабля
- **Пробел** - стрельба
- **R** - перезапуск после проигрыша
- **ESC** - выход из игры

## Хранение данных
Игра создает свою запись в:
- **Windows**: Реестр по пути `HKEY_CURRENT_USER\Software\SpaceShooterGame`
- **Linux/Mac**: Файл `~/.space_shooter_game/config.json`

### 10 сохраняемых значений:
1. GameVersion - версия игры
2. MaxScore - максимальный счет
3. PlayerName - имя игрока
4. Difficulty - уровень сложности
5. SoundEnabled - включение звука
6. MusicVolume - громкость музыки
7. EffectsVolume - громкость эффектов
8. ScreenMode - режим экрана
9. Language - язык интерфейса
10. LastPlayed - дата последнего запуска

## Как играть
Управляйте синим космическим кораблем, уничтожайте красные вражеские корабли и набирайте очки. Избегайте столкновений с врагами!
