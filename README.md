## GAIA — мини-ИИ в стиле Horizon

`gaia.py` — оффлайн чат-бот, отвечающий в стиле ИИ GAIA из Horizon Zero Dawn / Forbidden West:
спокойно, аналитически, с отсылками к экосистемам, машинам и восстановлению Земли.
Работает без внешних API и ключей, на основе сопоставления ключевых слов.

Запуск:

```bash
python3 gaia.py
```

Для выхода введите `пока` или `exit`.
